# 我的工作台（本地版）

这是一个不使用云端的个人任务工具。任务、记录、经验和图片都保存在本机 `data` 文件夹中。

## 启动

在 Windows PowerShell 中运行：

```powershell
.\run.ps1
```

也可以直接运行：

```powershell
python .\server.py
```

启动后：

- 电脑打开终端里显示的 `http://127.0.0.1:8765`
- 手机与电脑连接同一 Wi‑Fi，然后打开终端里显示的局域网地址

电脑必须保持工具运行，手机才能访问。数据不会上传到云端。

## 本地提醒

本地提醒默认是每天 08:40，可以在“设置”里修改。提醒依赖打开的工作台页面；电脑关机或页面关闭时不会在手机上推送。

## 备份

在“设置”点击“下载备份”，会导出包含任务、经验和本地附件的 ZIP 文件。建议定期复制到 U 盘或移动硬盘。

## 在另一台电脑独立使用

本工具的程序代码和本地数据是分开的：代码在 `index.html`、`server.py` 等文件中，数据在当前电脑自己的 `data` 文件夹中。A、B 两台电脑可以各自运行一份，互不共享数据，也不要求 A 电脑开机。

如果使用 GitHub 分发程序，只上传代码文件，不要上传 `data`、备份文件或截图。B 电脑克隆代码后运行 `python .\server.py`，首次启动会自动创建 B 电脑自己的空数据目录。

如果目标电脑没有 Python，可以使用发布目录中的 `我的工作台.exe`。双击后在浏览器打开 `http://127.0.0.1:8765`；数据会保存在 exe 同目录下的 `data` 文件夹中，关闭窗口即可停止服务。

## 浏览器离线版

打开 `我的工作台-浏览器版.html` 即可使用，无需 Python、Node、EXE 或管理员权限。任务、工作记录、设置和截图会保存在当前浏览器的 IndexedDB 中，每台电脑、每个浏览器彼此独立。浏览器版不提供局域网手机访问；请在“设置”中使用导出备份和导入备份迁移数据。
